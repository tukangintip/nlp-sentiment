Saya salah satu pengguna kartu XL ingin menyampaikan keluhan terkait dengan akses aplikasi myXL di nomor saya. Saya ingin membeli pulsa maupun paket, tetapi ketika mengakses myXL tidak bisa. Saat membuka aplikasi, responsnya hanya logo myXL atau muncul tulisan “cek koneksi”. Sekalinya bisa masuk, proses loading sangat lama, padahal saya mengakses menggunakan Wi-Fi.
Saya sudah mencoba menghubungi customer service melalui telepon 817. Namun yang muncul hanya pesan suara lama sekali dan tidak tersambung ke CS. Ingin chat melalui live chat, tetapi aplikasi myXL tidak bisa dibuka. Lalu bagaimana cara menghubungi CS untuk keluhan aplikasi myXL saya ini?
Saya sudah mencoba membersihkan cache aplikasi juga login logout, tetapi tetap saja responsnya “cek koneksi” dan harus berulang kali baru bisa. Tidak langsung cepat memunculkan tampilan, namun harus menunggu beberapa waktu hingga fitur tampilan awal muncul.
Kenapa ya? Padahal jika saya mengakses aplikasi lain bisa, seharusnya aman-aman saja untuk mengakses aplikasi myXL. Yang saya heran, aplikasi ini sudah sering diperbarui ke versi terbaru namun masih sering berkendala — salahnya di mana?
Sebelumnya nomor istri saya juga mengalami error pada aplikasi, tetapi sudah terselesaikan setelah dibuatkan laporan. Apakah memang harus laporan dulu baru bisa terselesaikan? Lalu, buat apa selalu update myXL jika masalahnya terus berulang? Sudah banyak pengguna yang mengeluhkan mengenai kendala aplikasi myXL. Seharusnya jika sudah update, aplikasi makin bagus, tapi nyatanya masih sama.
Melalui surat ke Media Konsumen ini, saya berharap keluhan kepada XL dapat tersampaikan. Karena jujur, saya bingung harus menghubungi CS lewat mana. Lewat chat aplikasi tidak bisa, telepon 817 dijawab bot dan lama mengantre, sedangkan saya sebagai pengguna baru sudah dikecewakan seperti ini.
